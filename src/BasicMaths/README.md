# 🔢 Basic Maths

Fundamental number-based problems that build logic and loop/condition skills,
the foundation for everything in DSA.

## Concepts Covered
- Digit extraction (using `%` and `//`)
- Counting and reversing digits
- Palindrome and Armstrong numbers
- GCD / HCF and LCM
- Prime numbers and divisors
